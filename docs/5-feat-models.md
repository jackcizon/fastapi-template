# Feat Models

1. 不再使用`sqlmodel`, 功能太差且完全不如`sqlalchemy`.
2. 不再对`models.py`进行单元测试和进行测试覆盖度报告.
3. 数据库不设置`FK`, 所有关联语义只存在于`ORM`
4. 删除默认是`soft delete`
5. 所有(级联)删除必须只写在`Service`层
6. 查询时统一过滤被删除的数据
7. 主键在本表里不用管（天然索引）, 但一旦这个主键
   出现在“其他表”里 → 当逻辑外键 → 默认加 index
8. 如果禁用 FK(基本必须做)，那么 `x-x(x in [1, m, n])`关系
   只能且必须靠`Service`层保证
9. `index`索引只是提速，保证在不使用`FK`时，使用代码`service`判断
   表关系时不至于速度更慢。
